# 未来展望

## 学校作文模板

下一项可评估的教学功能是学校作文模板，本轮尚未实施。

模板由管理员或授权老师建立，建议字段包括：

- 适用年级范围
- 作文题目
- 写作要求
- 评分标准
- 字数要求
- 标签
- 可见范围
- 模板版本

老师布置作业时复制模板快照。模板之后被修改或停用，不影响已经创建的作业及其历史记录。

模板实施前需要确认：谁能发布校级模板、老师个人模板是否共享、旧版本保留期限，以及不同年级评分标准的审核责任。

## OCR 评估

OCR 扫描件识别已实现：老师上传扫描版 PDF 或图片作文时，可通过 ecnu-plus 多模态识别为文字后导入。后续仍可结合实际扫描件样本评估手写中文识别率、姓名和学号定位、成本与人工复核工作量，以决定是否需要调优提示词、页数上限或引入专门 OCR 服务。

## 长期边界

平台不规划以下功能：

- Redis 或独立分布式任务队列
- 多服务器和多学校租户
- 家长端
- 社交功能
- 公开学生排行榜
- 复杂消息与通知系统

平台的完善标准不是继续增加外围功能，而是：学年流转不破坏历史、每次作文拥有完整版本链、老师只能看到自己的正式作业、学生数据不越权、备份能够实际恢复、约 1000 人单校使用稳定。
